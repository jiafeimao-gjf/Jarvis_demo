## 文件管理技能

### 能力
- 读写任意文本文件
- 创建和删除目录
- 搜索文件内容
- 批量文件重命名

### 工具
- file.read — 读取文件内容
- file.write — 写入文件
- file.edit — 修改文件
- file.delete — 删除文件
- file.list — 列出目录
- file.mkdir — 创建目录
- bash — 执行 shell 命令（用于批量操作）
